# 热力设备图像识别词典

## 用途

本词典用于多模态模型在热源厂、锅炉房、热力站和供热管网图片中识别设备对象、隐患现象和风险线索。词典只定义“看到了什么”和“应检索什么”，不把视觉推断当作压力、温度、介质或法定结论。

## 设备对象词典

| 视觉对象 | 同义或相关词 | 重点关联规则 |
| --- | --- | --- |
| 锅炉本体 | 锅炉、炉体、炉墙、炉膛、烟道、炉拱 | R-BOILER-01、R-GAS-01 |
| 管道 | 蒸汽管道、热水管道、汽水管道、热力管线、母管 | R-PIPE-01、R-PIPE-02、R-PIPE-03 |
| 阀门 | 截止阀、闸阀、调节阀、疏水阀、放空阀、安全阀 | R-PIPE-01、R-BOILER-02、R-MARK-01 |
| 连接部位 | 法兰、焊口、弯头、三通、补偿器、伸缩节 | R-PIPE-01、R-PIPE-03 |
| 支撑构件 | 管架、支架、吊架、固定支架、活动支架、基础 | R-PIPE-03 |
| 换热设备 | 换热器、板式换热器、壳管换热器、热力站 | R-PIPE-01、R-PIPE-02、R-PIPE-04 |
| 仪表和保护 | 压力表、温度计、水位计、报警器、联锁、控制柜 | R-BOILER-02、R-ELECTRIC-01 |
| 燃料系统 | 燃气管道、燃油泵、油箱、燃烧器、放散管 | R-GAS-01 |
| 消防设施 | 灭火器、消火栓、报警器、喷淋、疏散标志 | R-FIRE-01 |
| 地下设施 | 管沟、检查室、阀门井、热力井、地下泵站 | R-PIPE-04、R-SPACE-01 |
| 作业防护 | 护栏、平台、爬梯、盖板、围挡、警示牌 | R-ACCESS-01、R-SPACE-01、R-MARK-01 |

## 可见隐患现象词典

| 可见现象 | 推荐描述 | 不可直接推断 | 召回规则 |
| --- | --- | --- | --- |
| 红褐色锈蚀 | 构件表面存在明显锈蚀或腐蚀产物 | 剩余壁厚、腐蚀速率、是否穿孔 | R-PIPE-01、R-HEAT-02 |
| 锈水流痕 | 墙面或设备表面存在沿连接处向下的锈水痕迹 | 泄漏介质、泄漏起始时间 | R-PIPE-01、R-HEAT-02 |
| 滴漏或湿痕 | 法兰、阀门、焊口附近存在滴漏、湿润或水迹 | 压力、温度、介质危险性 | R-PIPE-01 |
| 保温脱落 | 管道或换热设备保温层、外护层破损或缺失 | 表面温度、保温下腐蚀程度 | R-PIPE-02 |
| 支架变形 | 管架倾斜、脱焊、断裂、管道下沉或悬空 | 承载能力、设计荷载 | R-PIPE-03 |
| 积水 | 管沟、热力站地面或电气设备附近积水 | 水源、深度、是否带电 | R-PIPE-04、R-ELECTRIC-01 |
| 裂纹和剥落 | 炉墙、墙面、基础或构件存在裂纹、剥落 | 是否影响承压或承重 | R-BOILER-01、R-ACCESS-01 |
| 裸露带电部位 | 电气柜、端子、线缆或开关防护缺失 | 是否带电、保护动作 | R-ELECTRIC-01 |
| 防护缺失 | 护栏、盖板、平台边缘、围挡或警示缺失 | 高度、人员暴露、替代措施 | R-ACCESS-01、R-SPACE-01 |
| 标识缺失 | 管道颜色、介质、流向、阀门编号或警示牌不清 | 是否发生误操作 | R-MARK-01 |
| 堵塞占压 | 通道、出口、管线保护范围被物料或施工占用 | 地下管线具体位置和损伤程度 | R-FIRE-01、R-OUTSIDE-01 |

## 图像输出格式建议

```json
{
  "object": "管道及阀门组",
  "observation": "连接部位存在红褐色锈蚀，墙面有向下锈水痕迹",
  "risk_hint": "疑似渗漏或腐蚀风险，需核验介质、压力和壁厚",
  "candidate_rules": ["R-PIPE-01", "R-HEAT-02"],
  "manual_review_items": ["确认泄漏介质和运行压力", "测厚并核对最近一次检验记录"],
  "region_required": true
}
```

## 识别禁区

- 不从锈蚀颜色推断压力等级、介质毒性或泄漏温度。
- 不从图片确认安全阀、联锁、报警、接地和消防系统“有效”或“失效”，除非有明确状态证据并仍要求现场复核。
- 不从设备外形推断设备编码、制造年份、检验有效期、责任人和整改期限。
- 不把“可能、疑似、需要核实”改写成“已发生、一定导致、必然重大”。
